Shared shares ปกติ   Solo password m=solo  ·  Workers นับจาก worker ที่เชื่อมต่ออยู่ (c=SYMBOL) ไม่ใช่ workerid เก่าใน shares (stratum ลบ/สร้าง worker ใหม่ทุกครั้งที่ reconnect)  ·  แถวจะปรากฏเฉพาะเหรียญที่มี shares/worker ใช้งานอยู่

TTF ต่อแถว = coin_nethash(coin) / pool_coin_rate(coinid, mode) × block_time (สูตรเดียวกับ TTF*** ในหน้า Pool — สำคัญเพราะบางเหรียญ เช่น LRS มี powlimit_bits = 0 การใช้ difficulty × 2^32 จะให้ค่าเพี้ยนหลักแสนปี)
